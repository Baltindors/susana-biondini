# Susana Biondini

Personal portfolio and blog for Susana Biondini. Built with Vue 3, Vite, Vue Router, and Markdown posts.

## Develop

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Deployed to GitHub Pages at `https://baltindors.github.io/susana-biondini/` (`vite.config.js` `base: '/susana-biondini/'`).
